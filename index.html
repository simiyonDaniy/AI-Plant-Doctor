How to prepare your model

  1. Open Teachable Machine in your browser.
  2. Choose Get Started → Image Project → Standard Image Model, if shown.
  3. Create classes such as Healthy Leaf, Damaged Leaf and Not a Leaf.
  4. Add varied examples to each class and train the model. Use photos you have permission to use.
  5. Export/share the model to a hosted URL, then paste that URL into the box above.
  6. Test with new photos not used for training. If it gives poor predictions, add better examples and retrain.

A classifier trained on “healthy” and “damaged” leaves learns those visual categories; it does not automatically know the exact disease or the right treatment.
